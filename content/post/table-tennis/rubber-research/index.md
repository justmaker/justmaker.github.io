# 全面性的乒乓球膠皮分析：種類、指標、候選池與實戰定位

這篇的目的不是只記「我現在買了什麼」，
而是建立一個**研究型膠皮 KB**：

- 已經買過的
- 正在用的
- 看過、感興趣的
- 之後可能會買來試的
- 理論上適合我，但還沒下手的

全部都可以先收進來。

這樣做的好處是：
- 之後不會每次又從零開始研究
- 可以用一致指標比較，不靠模糊印象
- 可以把「我有興趣」和「我真正適合」分開
- 可以把底板、打法、正反手需求一起考慮

---

## 一、這篇怎麼讀

這篇分成四層：

1. **先建立統一分析指標**
2. **再看膠皮大類的世界觀**
3. **建立候選池總表**
4. **逐張膠皮用同一套模板記錄**

目標不是一次就寫完所有膠皮，
而是建立一個可以持續擴充的框架。

## 二、統一分析指標（每張膠皮都要有）

為了讓不同膠皮之間能比較客觀地橫向對照，
這篇之後每個標的都盡量補齊同一組欄位。

### 1. 重量
- 裸膠重量（cut 前）
- 裁切後估計重量（cut 後）
- 對整拍平衡的影響

> 重量非常重要。很多膠皮不是性能不好，而是「太重」導致整拍不好打。

### 2. 速度
- 小力量速度
- 大力量上限
- 是一速快，還是二速 / 三速強？

### 3. 旋轉
- 主動摩擦時的上旋能力
- 發球、搓球、台內小球的旋轉品質
- 借轉 / 製造轉的能力

### 4. 吃球時間（持球感）
- 球停留在膠皮上的時間長不長？
- 容不容易「包住球」？

### 5. 出球弧線
- 弧線高 / 中 / 低
- 容不容易過網
- 第一板上手容不容易

### 6. 吃球深度
- 球是黏在表面，還是會明顯吃進海綿？
- 深吃球通常跟形變、旋轉、吞吐感有關

### 7. 小力量表現
- 台內、擺短、擰拉、借力、撥球時好不好控制？
- 會不會小力量就太噴？

### 8. 大力量表現
- 全力拉衝時有沒有上限？
- 球質會不會被打薄？
- 是越打越爽，還是一下就到頂？

### 9. 台內手感
- 擺短
- 挑打
- 搓球
- 擰拉
- 控短與手感細節

### 10. 擋 / 借力 / 反手友善度
- 對反手來說會不會太重、太硬、太黏？
- 借力防守時穩不穩？
- 對快撥、擋、借力對拉友不友善？

### 11. 容錯
- 第一板容不容易上台？
- 擊球點不完美時會不會掉很多？
- 對腳步沒那麼到位時有沒有寬容度？

### 12. 硬度 / 海綿感
- 官方硬度
- 實際打感是偏硬、偏中、偏軟？
- 是表面硬、底下軟，還是整體都硬？

### 13. 壽命 / 耐打度
- 膠面多久明顯衰退？
- 海綿疲勞速度如何？
- 是性能好但很短命，還是比較耐久？

### 14. 適合位置
- 適合正手
- 適合反手
- 雙面都行

### 15. 適合底板
- 適合純木 / 外置 / 內置
- 適合柔和板 / 硬挺板 / 輕量板 / 厚重板

### 16. 適合打法
- 快攻
- 快弧
- 弧快
- 兩面攻
- 正手主導
- 反手主動
- 控制優先

### 17. 個人標籤
- 我有興趣
- 我可能會買
- 我已買 / 用過
- 我不考慮
- 適合我正手
- 適合我反手
- 適合 XVT
- 適合單檜
- 太重
- 太噴
- 太硬
- 耐打可接受

## 三、先分膠皮大類

### 1. 黏性（Sticky / Tacky）
- 代表：狂飆、Battle、Big Dipper、Jupiter、部分國套 / 中套
- 主題：主動摩擦、發力後球質、台內控制、發球旋轉
- 代價：通常比較重，借力沒那麼自然，反手不一定友善

### 2. 微黏（Semi-sticky / Hybrid）
- 代表：Dignics 09c、K3、某些混合型德套
- 主題：想兼得一點黏性台內感 + 德套現代彈性
- 代價：常常價格高、重量重、個性比較吃搭配

### 3. 澀性（Tensor / Grippy Inverted）
- 代表：G-1、C-1、Rakza 系、DNA 系、Tenergy 系、Vega 系
- 主題：現代感、彈性、借力、反手友善度較高
- 代價：有些會小力量太噴，或壽命衰退較快

## 六、重點候選與第一批完整展開

> 這一版先把你明確點名、且很值得當基準物的幾張先完整展開：

> 這幾張有一個共同價值：

### 1. Tenergy 05
- 中文 / English：Tenergy 05
- 類型：澀性 / High-friction Tensor
- 官方硬度：36°（Butterfly 日系標法）
- 常見厚度：1.9 / 2.1
- 裸膠重量：中偏重
- 裁切後重量（估計）：重於多數一般反手套，正手較常見

#### 核心評價
- **速度：** 中高到高，發力後上限高
- **旋轉：** 很高，是經典的旋轉代表之一
- **吃球時間：** 中長
- **出球弧線：** 高
- **吃球深度：** 中深
- **小力量表現：** 不算最省力，但摩擦感很明顯
- **大力量上限：** 很高，越發力越能感受到它的上限
- **台內手感：** 旋轉製造力強，但若手太粗也容易彈長
- **擋 / 借力 / 反手友善度：** 可打反手，但不是所有人都會覺得友善；對反手來說有點挑人
- **容錯：** 不低，但不是那種「什麼都幫你吃掉」的鈍感型容錯
- **實際打感硬度：** 中偏硬，但因抓球感強，不會只剩硬
- **壽命 / 耐打度：** 高階日套中算有口碑，但價格高

#### 定位
- **適合正手 / 反手：** 正手更經典；高階反手也有人用
- **適合底板：** 純木、內置、外置都能搭，但太彈的底板上可能更吃手
- **適合打法：** 弧圈主導、兩面攻、高旋轉路線

#### 一句話
**T05 是「高弧線、高旋轉、高上限」的經典標尺。**

### 2. Tenergy 64
- 中文 / English：Tenergy 64
- 類型：澀性 / High-friction Tensor
- 官方硬度：36°
- 常見厚度：1.9 / 2.1
- 裸膠重量：中偏重
- 裁切後重量（估計）：與 05 同級，但體感常被覺得更輕快

#### 核心評價
- **速度：** 高，一速感比 T05 更明顯
- **旋轉：** 高，但一般認知略低於 T05
- **吃球時間：** 中
- **出球弧線：** 中
- **吃球深度：** 中
- **小力量表現：** 借力感好，反應快
- **大力量上限：** 高，但主題比較偏速度流暢而不是極端旋轉厚重
- **台內手感：** 比 T05 更容易覺得「球出去得快」
- **擋 / 借力 / 反手友善度：** 很多人會覺得比 T05 更適合反手或快節奏對抗
- **容錯：** 中高
- **實際打感硬度：** 中，體感比 T05 更輕快、更彈
- **壽命 / 耐打度：** 跟 Tenergy 系列同級

#### 定位
- **適合正手 / 反手：** 反手特別常見，正手也可
- **適合底板：** 適合想把近台節奏拉快的板子
- **適合打法：** 快弧、快攻結合、反手主動、借力對抗

#### 一句話
**T64 是「速度感、流暢感、借力感」更強的 Tenergy 分支。**

### 4. Tenergy 19
- 中文 / English：Tenergy 19
- 類型：澀性 / High-friction Tensor
- 官方硬度：36°
- 常見厚度：1.9 / 2.1
- 裸膠重量：中偏重
- 裁切後重量（估計）：與 T05 接近

#### 核心評價
- **速度：** 中高
- **旋轉：** 高
- **吃球時間：** 中
- **出球弧線：** 中高
- **吃球深度：** 中
- **小力量表現：** 比 T05 更容易覺得穩，沒有那麼挑細節
- **大力量上限：** 高

## 七、怎麼看 T05 / T64 / T80 / T19 / R7 這五張的差異？

如果硬要超濃縮：

- **T05**：旋轉 / 弧線代表
- **T64**：速度 / 借力 / 流暢代表
- **T80**：中間均衡折衷代表
- **T19**：更穩、更反手向的高階 Tenergy 線
- **R7**：不走極端，但很能長期主戰的穩定派

### 很實用的記法
- 想要「最像經典高旋轉日本高階套」 → **T05**
- 想要「更快更流暢」 → **T64**
- 想要「中庸均衡」 → **T80**
- 想要「高階反手 / 更完整的現代節奏」 → **T19**
- 想要「不用每一板都那麼緊張，但整體很能打」 → **Rakza 7**
