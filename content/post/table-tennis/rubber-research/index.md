# 全面性的乒乓球膠皮分析：種類、指標、候選池與實戰定位

這篇的目的不是只記「我現在買了什麼」，
而是建立一個**研究型膠皮 KB**：

- 已經買過的
- 正在用的
- 看過、感興趣的
- 之後可能會買來試的
- 理論上適合我，但還沒下手的

全部都可以先收進來。

這樣做的好處是：
- 之後不會每次又從零開始研究
- 可以用一致指標比較，不靠模糊印象
- 可以把「我有興趣」和「我真正適合」分開
- 可以把底板、打法、正反手需求一起考慮

---

## 一、這篇怎麼讀

這篇分成四層：

1. **先建立統一分析指標**
2. **再看膠皮大類的世界觀**
3. **建立候選池總表**
4. **逐張膠皮用同一套模板記錄**

目標不是一次就寫完所有膠皮，
而是建立一個可以持續擴充的框架。

---

## 二、統一分析指標（每張膠皮都要有）

為了讓不同膠皮之間能比較客觀地橫向對照，
這篇之後每個標的都盡量補齊同一組欄位。

### 1. 重量
- 裸膠重量（cut 前）
- 裁切後估計重量（cut 後）
- 對整拍平衡的影響

> 重量非常重要。很多膠皮不是性能不好，而是「太重」導致整拍不好打。

### 2. 速度
- 小力量速度
- 大力量上限
- 是一速快，還是二速 / 三速強？

### 3. 旋轉
- 主動摩擦時的上旋能力
- 發球、搓球、台內小球的旋轉品質
- 借轉 / 製造轉的能力

### 4. 吃球時間（持球感）
- 球停留在膠皮上的時間長不長？
- 容不容易「包住球」？

### 5. 出球弧線
- 弧線高 / 中 / 低
- 容不容易過網
- 第一板上手容不容易

### 6. 吃球深度
- 球是黏在表面，還是會明顯吃進海綿？
- 深吃球通常跟形變、旋轉、吞吐感有關

### 7. 小力量表現
- 台內、擺短、擰拉、借力、撥球時好不好控制？
- 會不會小力量就太噴？

### 8. 大力量表現
- 全力拉衝時有沒有上限？
- 球質會不會被打薄？
- 是越打越爽，還是一下就到頂？

### 9. 台內手感
- 擺短
- 挑打
- 搓球
- 擰拉
- 控短與手感細節

### 10. 擋 / 借力 / 反手友善度
- 對反手來說會不會太重、太硬、太黏？
- 借力防守時穩不穩？
- 對快撥、擋、借力對拉友不友善？

### 11. 容錯
- 第一板容不容易上台？
- 擊球點不完美時會不會掉很多？
- 對腳步沒那麼到位時有沒有寬容度？

### 12. 硬度 / 海綿感
- 官方硬度
- 實際打感是偏硬、偏中、偏軟？
- 是表面硬、底下軟，還是整體都硬？

### 13. 壽命 / 耐打度
- 膠面多久明顯衰退？
- 海綿疲勞速度如何？
- 是性能好但很短命，還是比較耐久？

### 14. 適合位置
- 適合正手
- 適合反手
- 雙面都行

### 15. 適合底板
- 適合純木 / 外置 / 內置
- 適合柔和板 / 硬挺板 / 輕量板 / 厚重板

### 16. 適合打法
- 快攻
- 快弧
- 弧快
- 兩面攻
- 正手主導
- 反手主動
- 控制優先

### 17. 個人標籤
- 我有興趣
- 我可能會買
- 我已買 / 用過
- 我不考慮
- 適合我正手
- 適合我反手
- 適合 XVT
- 適合單檜
- 太重
- 太噴
- 太硬
- 耐打可接受

## 三、先分膠皮大類

### 1. 黏性（Sticky / Tacky）
- 代表：狂飆、Battle、Big Dipper、Jupiter、部分國套 / 中套
- 主題：主動摩擦、發力後球質、台內控制、發球旋轉
- 代價：通常比較重，借力沒那麼自然，反手不一定友善

### 2. 微黏（Semi-sticky / Hybrid）
- 代表：Dignics 09c、K3、某些混合型德套
- 主題：想兼得一點黏性台內感 + 德套現代彈性
- 代價：常常價格高、重量重、個性比較吃搭配

### 3. 澀性（Tensor / Grippy Inverted）
- 代表：G-1、C-1、Rakza 系、DNA 系、Tenergy 系、Vega 系
- 主題：現代感、彈性、借力、反手友善度較高
- 代價：有些會小力量太噴，或壽命衰退較快

## 六、先做第一批重點候選（之後再逐張補滿）

### 1. Fastarc G-1
- 中文 / English：Fastarc G-1
- 類型：澀性
- 重量：中偏重
- 定位：萬用型現代正手基準，也可當較強反手
- 關鍵字：穩、紮實、上限高、容錯不差、很像「標準答案」
- 個人標籤：**高度 relevant**

### 2. Fastarc C-1
- 中文 / English：Fastarc C-1
- 類型：澀性
- 重量：中
- 定位：反手友善型現代澀套
- 關鍵字：柔和、借力、容錯、比 G-1 更適合反手
- 個人標籤：**高度 relevant**

### 3. Rakza 7 Soft
- 中文 / English：Rakza 7 Soft
- 類型：澀性
- 重量：中
- 定位：反手友善、吃球感佳、傳統穩定派
- 關鍵字：好上手、持球、控制、耐打度通常不差
- 個人標籤：**高度 relevant**

### 4. Dignics 09c
- 中文 / English：Dignics 09c
- 類型：微黏 / Hybrid
- 重量：重
- 定位：高階正手
- 關鍵字：質量高、弧圈重、台內強，但重且吃搭配
- 個人標籤：**理論上強，但成本與重量門檻高**

### 5. Tibhar Hybrid K3
- 中文 / English：Hybrid K3
- 類型：微黏 / Hybrid
- 重量：重
- 定位：高階正手 / 重混合派
- 關鍵字：混合派代表、質量強、重、對反手不一定友善
- 個人標籤：**值得研究，但要小心重量**

### 6. Tenergy 05 / Tenergy 19
- 中文 / English：Tenergy 05 / Tenergy 19
- 類型：澀性
- 重量：中偏重
- 定位：經典高階日套
- 關鍵字：05 = 旋轉與弧線代表；19 = 更穩、更反手向
- 個人標籤：**經典基準，值得當對照物**
