# AKKADI TW 2700-08 桌球發球機

我目前使用的桌球發球機是 **AKKADI TW 2700-08**。這是一台可程式化的雙輪發球機，能設定旋轉、速度、落點、長短球、出球數量與訓練時間，適合用來進行固定動作、多點步法與前後移動訓練。

## 核心功能

### 雙輪與七種旋轉

上下雙輪可透過轉速搭配改變出球旋轉。原廠型錄列出七種旋轉類型，可用於練習上旋、下旋、側旋及其組合球路；雙輪結構也比單輪機更容易做出接近無旋轉的球。

### 固定、隨機與自訂球路

原廠提供三類主要模式：

- **固定模式：** 持續送到同一落點，適合單項技術定型。
- **隨機模式：** 可選全檯、左半檯或右半檯隨機落點，適合反應與步法訓練。
- **自訂模式：** 自行編排落點順序，建立固定的多球套路。

### 長短球混合

可設定長球與短球，並搭配固定、隨機或自訂模式。這項功能適合練習近網處理後銜接後退進攻，也能強化前後步法與重心調整。

> **版本提醒：** 網路流傳的 `TW-2700-V1` 英文手冊，遙控器只顯示 5 個左右落點，沒有獨立的 `Long` / `Short` 鍵。它不能直接證明每一球都能個別指定長短；若實機面板與手冊不同，應以 **TW 2700-08 實機遙控器與原廠說明**為準。

### 記憶、計數與計時

機器可記住前一次編輯的球路順序，重新開機後繼續使用。訓練時也能限制球數或時間，並顯示累計出球數與使用時間。遙控器可放在球桌附近，方便在訓練中調整設定。

### 自動回收循環

搭配集球網後，打出的球會回到機器並持續循環，可減少撿球與重新裝球的中斷時間。

## 自編落點操作

以下步驟依 `TW-2700-V1` 英文操作手冊整理，適用於該手冊所示的五點式遙控器：

1. **進入編程：** 按下 `Set/Save（編輯／儲存）`。畫面上的自編模式、落點與序號指示會閃爍；若機器正在出球，會先停止並進入編程。
2. **選擇落點：** 使用 `Left` 或 `Right`，在畫面上由左至右的 1–5 號落點間移動。
3. **確認每一球：** 選好落點後按 `Set/Save`，畫面顯示 `01`；依同樣方式繼續輸入第 2、3、4 球。單一程序最多可設定 **30 球**，也可以重複相同落點。
4. **啟動程序：** 完成後按 `On/Off（開／暫）` 開始出球。新程序會覆蓋前一套程序。
5. **調整參數：** 編程過程中不能調整旋轉、出球頻率與弧線；啟動出球後再調整上下輪轉速、頻率，以及機頭上的 `Curve knob（弧線旋鈕）`。

若兩分鐘內沒有輸入，機器會自動離開編程模式。操作時每次收到遙控訊號，機器會發出提示音。

### 如何處理長短球

原廠 TW 2700-08 型錄記載可搭配模式設定長、短落點，但 `TW-2700-V1` 手冊沒有列出逐球長短編輯流程。弧線旋鈕只能調整整體出球弧線：順時針降低弧線，逆時針提高弧線。因此，在確認實機具有逐球長短設定前，不應把調整弧線旋鈕當成自動長短交替。

## 原廠規格整理

| 項目 | 規格 |
|---|---|
| 出球頻率 | 每分鐘 30–100 球 |
| 出球速度 | 4–50 m/s |
| 落點範圍 | 固定點至全檯範圍 |
| 弧線調整 | 45° |
| 球數設定 | 1–900 球 |
| 計時設定 | 1–120 分鐘 |
| 定量訓練 | 10–900 球，每次增加 10 球 |
| 長短球 | 可選擇長、短落點距離 |

## 建議訓練菜單

### 1. 固定點動作定型

先以中低球速固定送到正手或反手位，每組 30–50 球。重點放在擊球點、重心轉換與每球還原，不追求單球力量。

### 2. 左右兩點步法

設定左右落點交替，練習併步或小碎步移動。先從固定順序開始，穩定後再改成半檯或全檯隨機。

### 3. 短球接長球（需實機支援逐球長短設定）

自訂短球與長球交替，例如短球處理後接正手長球。重點是進台後迅速還原，避免身體停在桌內。

可先嘗試兩套球路：

- **搓中起板：** 正手短球 → 正手長球，練習台內控制後迅速後撤起板。
- **前後左右步法：** 反手短球 → 正手長球 → 正手短球 → 反手長球，練習連續進退與左右銜接。

如果實機只能編排左右落點、不能逐球指定深淺，這兩套菜單就需要分段練習，或由陪練者手動切換設定，不能直接用單一自編程序完成。

### 4. 全檯隨機反應

使用全檯隨機模式，以可控制的速度連續訓練。優先確保站位、判斷與還原，再逐步提高頻率。

### 5. 定量或計時訓練

可用 100 球為一組，或設定 3–5 分鐘連續訓練，方便記錄完成率、失誤位置與體能變化。

## 使用上的限制

發球機很適合重複練習，但不能完全取代真人對打。固定機械出球無法完整模擬對手的動作欺騙、臨場節奏、旋轉細微變化與發球隱蔽性，因此仍需搭配多球、對練及比賽驗收。
