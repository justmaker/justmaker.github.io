# 桌球底板材料分析：面材、內置/外置與複合纖維

這篇現在的角色是 **底板材料總論頁**。

它要處理的不是我手上哪一支拍最適合，
而是更底層的材料問題，例如：

- 面材個性差異
- 內置 / 外置差異
- 碳纖、ALC、ZLC、SALC、SZLC、玻纖、鈦纖的差異
- 哪些面材比較怕拔絲
- 哪些材質比較適合不同階段的選手

也就是說：

- 如果你想看 **我自己的器材主線**，請看 [`my-equipment`](/post/table-tennis/my-equipment/)
- 如果你想看 **材料本身的世界觀**，看這篇就對了

---

## 一、面材個性：先決定你摸到的是什麼世界

面材是底板最外層木材，
它會直接影響：

- 吃球感
- 脫板速度
- 手感柔和或硬挺
- 觸球時的「木味」
- 拆膠時表層耐不耐折騰

### 常見面材的個性印象

| 面材 | 常見個性 | 白話印象 |
|------|---------|---------|
| Limba | 柔和、吃球、吞吐感好 | 很有弧圈味，但較怕拔絲 |
| Koto | 硬挺、清脆、出球直接 | 俐落、拍面清楚 |
| Hinoki | 柔和、通透、彈中帶吞 | 木味迷人，但表層要小心 |
| Rosewood | 硬、密、脆、紮實 | 高級感強，較抗拔絲 |
| Ebony | 更硬、更密、更緊 | 相對更抗拔絲，但個性也更硬朗 |
| Walnut | 紮實、穩、偏硬 | 介於木味與硬朗之間 |
| Ayous | 常見於內層 / 大芯 | 外層較少當主角，個性中間 |
| Kiri | 輕、軟，多見於大芯 | 如果當外層通常不算很耐折騰 |

## 二、常見面材抗拉絲（抗拔絲）程度排序

這裡整理的是：

## **常見乒乓底板面材，在拆膠 / 換膠時，表層抗拉絲、抗拔木絲的大致程度。**

先講最重要前提：

- 這不是絕對定律
- 不同廠商的表面處理、壓面、打磨、封板狀態都會影響結果
- 同樣的木種，不同個體也可能有差
- 膠水厚薄、是否乾透、拆膠手法，常常比木種本身還更直接影響結果

所以這張表比較像：

## **在一般未重封板、正常水性膠施工的前提下，常見面材對拉木絲風險的相對排序。**

### 大方向排序（由抗拉絲高 → 低）

1. **黑檀木（Ebony）**
2. **玫瑰木（Rosewood）**
3. **胡桃木（Walnut）**
4. **Koto**
5. **Kiri / 桐木面材（若作外層）**
6. **Ayous / 阿尤斯（若作外層）**
7. **Hinoki / 檜木**
8. **Limba**

> 如果只抓一句話：
> **一般來說，硬、密、表面緊的木種比較抗拉絲；軟、鬆、纖維感強的木種比較怕拔絲。**

### 實戰版收斂

#### 比較放心的
- **黑檀木**
- **玫瑰木**
- **胡桃木**
- **Koto**

#### 中間地帶
- **Ayous（若作外層）**
- **Kiri（若作外層）**

#### 比較要保守對待的
- **Hinoki**
- **Limba**

#### 最實用的結論

如果之後會：
- 常換膠
- 常試不同膠皮
- 想降低拉木絲風險

那就要記住：

## **柔和好吃球的面材，往往也是更需要小心拆膠與更值得輕封板的面材。**

尤其是：
- **Limba**
- **Hinoki**

## 三、內置 / 外置：纖維層放在哪裡，手感差很多

這主要指的是底板中 **纖維層的放置位置**。

### 1. 內置纖維 (Inner)

* **結構：** 纖維層靠近大芯，外層木材較厚。
* **特性：**
  * 手感更接近純木
  * 吃球感較好
  * 持球時間相對較長
  * 速度比外置略收，但仍有纖維底勁
  * 需要主動發力時更能感受到「後段彈」
* **適合：**
  * 想要弧圈質量、控制、持球感的人
  * 不想一上來就太衝的人

### 2. 外置纖維 (Outer)

* **結構：** 纖維層靠近面材。
* **特性：**
  * 出球更直接
  * 速度更快
  * 小力量就容易感受到纖維的彈性
  * 手感通常更硬挺、持球更短
  * 更容易有「一速」優勢
* **適合：**
  * 想要快、爆發、近台俐落感的人
  * 已經能處理更直接板身回饋的人

### 一句話版

- **內置**：比較像高級純木延伸版
- **外置**：比較像高級快板 / 爆發版

## 四、常見纖維材質比較：碳纖、ALC、ZLC、SALC、SZLC、玻纖、鈦纖

先講最白話的一句話版：

- **純碳 / Carbon**：直接、快、硬、清楚，最容易覺得「衝」
- **ALC**：高級均衡、穩、好上手
- **ZLC**：比 ALC 更彈、更大甜區、更高輸出
- **SALC**：ALC 的高級升級版，更完整、更俐落
- **SZLC**：ZLC 再往上推的大甜區高輸出版
- **玻纖 / Glass Fiber**：柔和、減震、比較不暴力
- **鈦纖 / Titanium Fiber**：紮實、金屬感、直接、指向性強

### 總表

| 材質 / 系統 | 速度 / 彈射 | 甜區 | 手感個性 | 控制體感 | 常見印象 |
|------------|------------|------|---------|---------|---------|
| 純碳 / Carbon | 高 | 大 | 硬、快、直接 | 中低 | 暴力、俐落、容易頂 |
| ALC | 中高 | 大 | 均衡、穩、成熟 | 高 | 高級但不暴衝 |
| SALC | 高 | 大～更大 | ALC 升級版，更乾淨更完整 | 中高 | 更高級、更精緻 |
| ZLC | 高 | 很大 | 更彈、更直接、更現代 | 中 | 神兵感、高輸出 |
| SZLC | 很高 | 很大～超大 | 更高輸出、更強板身 | 中低～中 | 神兵中的神兵 |
| 玻纖 / Glass Fiber | 中低～中 | 中 | 柔和、吸震、比較包 | 高 | 穩、順、不暴力 |
| 鈦纖 / Titanium Fiber | 中高 | 中～大 | 紮實、脆、金屬感、指向性強 | 中 | 一板感強、很有個性 |

### 用階段來理解

#### 比較友善、比較容易當長期主戰的高階線
- **ALC**
- **玻纖（若你偏柔和）**

#### 比較像高階推進線
- **ZLC**
- **SALC**

#### 比較像高階後段 / 神兵線
- **SZLC**

#### 比較像強烈風格板
- **純碳**
- **鈦纖**

## 五、怎麼把材料判讀落回實戰？

如果你是在選板，不要只看一個名詞就下決定。

### 你至少要一起看：
1. **面材** 是 Limba、Koto、Hinoki、Rosewood 還是其他？
2. **纖維位置** 是內置還是外置？
3. **複合材質** 是純碳、ALC、ZLC、SALC、SZLC、玻纖還是鈦纖？
4. **你現在的技術階段** 是需要更友善、更穩，還是已經要追高輸出？

### 簡化後的判讀方向

- 想要 **柔和、持球、弧圈感** → 看 Limba / Hinoki / 內置 / ALC / 玻纖
- 想要 **直接、俐落、拍面清楚** → 看 Koto / 純碳 / 外置 / 鈦纖
- 想要 **更高輸出與更大甜區** → 看 ZLC / SALC / SZLC
- 想要 **換膠時更省心** → 優先看 Ebony / Rosewood / Walnut / Koto 這些較抗拉絲面材

---

## 六、總結

* **面材** 決定了你最直接摸到的外層個性：柔和、吃球、硬挺、脆實、抗拉絲程度都先從這裡開始。
* **內置/外置** 決定了纖維層對擊球手感的影響程度：內置更柔和、持球，外置更硬挺、快速。
* **碳纖/碳素與其複合材料**（如 ALC、ZLC、SALC、SZLC）共同提升底板的速度、力量和甜區，但每一條線對控制、持球與刺激度的分布不同。

## **選擇底板時，不是只看一個材質名詞，而是要把面材、纖維位置、複合材料類型與自己的技術階段一起看。**
