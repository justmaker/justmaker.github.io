# 乒乓球底板材料分析：總覽與系列導讀

這篇文章的目標，不是只講「哪種材料比較高級」，
而是建立一套 **比較一致、可橫向對照** 的分析框架，
讓之後看到任何一支底板時，可以比較有系統地拆解它：

- 面材是什麼個性？
- 力材在幫什麼？
- 纖維層放哪裡、材質是什麼？
- 大芯提供的是輕、彈、底勁，還是穩、撐、厚重感？
- 不同位置用同一種木材，手感為什麼會不一樣？

也就是說，這篇不是「我的器材日記」，
而是 **底板材料世界觀的總整理**。
