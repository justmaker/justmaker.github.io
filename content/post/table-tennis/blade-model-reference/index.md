### 0. 本章具體底板型號表

本章討論的型號依資料狀態拆成三張互斥表格：

1. **現售且逐層材料明確**：才進入主要總表。
2. **已停產**：不論材料是否完整，一律移到停產表。
3. **逐層材料不明確**：尚未確認停產，但至少一層木種或纖維無法可靠確認。

每個型號只出現一次，避免同一筆資料散落在不同表格。完整層次統一由一側面材寫到另一側面材；對稱板沿箭頭讀完就是整支底板，不省略力材、纖維或大芯。

> **資料口徑（2026-08-26）**：木種與纖維優先採品牌官方資料，其次才是有實物照片、量測或拆解依據的零售 / 評測資料。不因外觀或「同結構」宣稱補猜材料。價位是裸板常見區間；跨境價格未含運費、關稅與選重費，停產板不列不穩定的二手喊價。

### 1. Butterfly Viscaria

#### 結構定位
- **Koto outer**
- **Outer ALC**
- **Kiri / Ayous 系核心邏輯**
- 5+2 外置高階主流模板

#### 大致個性
- 拍面清楚
- 出球直接
- 甜區大
- 小力量就能感受到纖維存在感
- 正反手都很好建立現代節奏

#### 適合誰
- 兩面攻
- 近台快弧
- 想要一支現代均衡高階主戰板的人

#### 一句話
**Viscaria 幾乎就是「外置 ALC 高階主戰板」的教科書模板。**

### 2. Butterfly Innerforce Layer ALC

#### 結構定位
- 常見為 **Limba outer**
- **Inner ALC**
- 5+2 內置經典模板

- 喜歡持球感
- 想要高級純木延伸感的人

#### 一句話
**Innerforce ALC 是「弧圈派內置 ALC」的經典母板。**

### 3. DHS 狂飆龍 5 / 龍 5 類

#### 結構定位
- 內置芳碳系
- 外層常偏向弧圈取向
- 整體是「中國系內置弧圈板」代表

#### 大致個性
- 吃球更重
- 弧圈味濃
- 一速不算兇，但二速三速比較有壓迫感
- 更吃完整發力

#### 適合誰
- 正手主動發力明確的人
- 弧圈主導、快弧 / 弧快過渡型
- 喜歡帶一點厚重感與中國系拉衝節奏的人

#### 一句話
**龍 5 類不是 Viscaria 那種一上手就俐落的外置路線，而是更重視完整發力後輸出的內置弧圈路線。**

### 3.1 三維、銀河的 Viscaria / W968 同結構候選

> 這裡的「仿」是指採用相近的木材層次、纖維位置與設計方向，不代表重量、膠合、木材篩選、形變曲線或實際手感能完整複製原板。

完整層次與價格統一看本章開頭的**具體底板型號總表**；這裡只保留路線定位，避免同一筆規格維護兩次。

#### 路線歸類

- **Viscaria / 外置快弧線**：三維 75 ALC → 銀河 V14 Pro / PRO-01 → 三維 Froster Pro。前兩者偏低價體驗，PRO-01 的近台節奏較成熟，Froster Pro 則往更高輸出與做工前進。
- **W968 / 龍 5 內置弧圈線**：銀河 PRO-05 → PRO-05X → PRO-05X Max，支撐、底勁與發力門檻逐步提高；970XX-K 是較早期、木感不同的分支。
- **三維直接對標 968 的分支**：SP 968 強調形變與蓄能方向，但不能因型號名稱就視為 W968 的等價品。

結構與價格來源集中列在總表及本章末的來源清單，包括：[BigGo 台灣比價（銀河 PRO-01）](https://biggo.com.tw/s/%E9%8A%80%E6%B2%B3%20PRO-01/)、[BigGo 台灣比價（銀河 PRO-05）](https://biggo.com.tw/s/%E9%8A%80%E6%B2%B3%20PRO-05/)、[BigGo 台灣比價（三維 75）](https://biggo.com.tw/s/%E4%B8%89%E7%B6%AD75%E7%90%83%E6%8B%8D/)、[BigGo 台灣比價（三維 SP-968）](https://biggo.com.tw/s/%E4%B8%89%E7%B6%AD%20SP-968/)、[Megaspin（三維 Froster Pro）](https://www.megaspin.net/store/default.asp?pid=sanwei-froster-pro)。

### 3.2 一面 VIS 外置、另一面龍 5 / W968 內置的雙面異質底板

這裡採用比「兩面異質」更嚴格的定義：**同一支底板的一面，纖維位於面材下方（outer，VIS 路線）；另一面，纖維靠近大芯（inner，龍 5 / W968 路線）**。只有兩面面材不同、軟硬不同，或廠商另外販售 inner / outer 兩個型號，都不算。

> **調查結論（截至 2026-08-25）**：11 個品牌中，確認有量產商品的是 **銀河、Tibhar（挺拔）與雙魚**。其中銀河 PRO-12S 的官方描述最直接，明寫「正手內置（像龍 5）、反手外置（像蝴蝶 VIS）」；其他型號雖確認一面內置、一面外置，但不一定公開完整木材與纖維規格，因此應理解成**功能與結構路線相近**，不是把 VIS 與 W968 原樣黏在一起。

### 3.3 PRO-01、PRO-05、三維 75、W81、VSEA 與 SWAT 怎麼看

這組底板剛好涵蓋三條常見的平價選板路線：**VIS 類外置複合、龍 5 類內置複合，以及容易控制的七夾純木**。價錢接近不代表用途相同，應先選結構方向，再比較品牌調校。

#### 銀河 PRO-01：平價外置快弧基準

- 小力量就有纖維反彈，擋、撥、彈擊與近台兩面銜接容易建立速度；拍面不像高硬外置那麼頂，仍保留一定吃球時間。
- 中遠台與大力量的絕對支撐不是它的強項。選到過輕個體時，正手重板和退台底勁更容易不足。
- 適合以近台快弧和反手銜接為主的人；不等於原版 Viscaria 的木材篩選與輸出上限。

#### 銀河 PRO-05：較容易使用的龍 5 路線

- 小力量有木感和持球，中等力量開始出現纖維支撐；起下旋、連續弧圈與落點控制比 PRO-01 寬容。
- 相較傳統龍 5 世界觀，PRO-05 的反手不算拖，借力和快帶相對容易；但第一速、彈擊爽脆感仍不如外置。
- 適合弧圈主導、想要旋轉與穩定，又不希望內置板小力量過於發空的人。

#### 三維 75：系列至少六款，不能只看同一個型號數字

- **75# 外置**是經典外置藍芳碳；**75 inner**則是內置藍芳碳，兩者分別偏出球乾脆與持球相持。
- **75R**是約 5.7mm、86～90g 的外置藍芳碳分支，弧線低平，偏近台快攻、顆粒膠和反手發力；不能把字尾 R 漏掉後併入普通 75 外置。
- **75G**是 Koto 面材、內置綠芳碳 G-ALC 分支，約 85～95g，偏擺速、旋轉、反手和纏鬥；也不是普通 75 inner 的改名。
- **超級 75 外置**是 Koto / Ayous / Kiri 搭配外置 PBO 混編；**超級 75 內置**是 Limba / Ayous 搭配內置 PBO 混編與 Ayous 大芯。兩款不只纖維位置不同，面材與大芯路線也不同。
- 外置分支適合借力、快撕與近台節奏；內置分支適合摩擦、弧圈與主動發力。這是打法分流，不是單純的高低階關係。
- 上述細分規格來自 2026-08-26 的三維 75 系列零售商商品詳情圖，屬次級來源；只有圖中明載的木種才寫入總表，未載明處不依結構類比臆測。

#### 雷神 W81：先看 ARC / ADC / ZC / SZC，再看內外置

- W81 是系列名，不是單一結構。公開市場資料至少可見外置 **ARC / ZC** 與內置 **ADC / SZC** 等版本；不同縮寫代表不同複合材料與調校。
- 外置版的特色是脆彈、穩定、線性，擋撥與借力速度好，屬於沒有明顯短板的水桶型外置。
- 內置版較持球，起下旋與中台弧圈的容錯更好，但需要更完整的主動發力；不同內置 SKU 的硬度、噴彈和反手表現可能明顯不同。
- 商品頁若只寫「W81 內置」或「W81 外置」，卻不列 ARC / ADC / ZC / SZC 與厚度重量，資訊不足，不宜直接把它當成固定配方購買。

#### 世奧得 VSEA：柔彈、清楚的低價內置

- 小力量不容易發空，中等力量容易透板；持球、旋轉和指向性清楚，正反手轉換也比較自然。
- 退台後的二跳和絕對力量仍不及高階 W968 類，但它的優勢本來就是低門檻、均衡與價格。
- 適合第一次嘗試內置纖維、以近中台弧圈和控制為主的人；若追求一板爆衝與極限底勁，應往更高支撐的內置板看。

#### VICTAS SWAT：七夾純木的控制與練功路線

- 標準 SWAT 不要和 SWAT Carbon、SWAT Speed、SWAT Power 混為一談。
- SW 炭燒 / 乾燥工藝讓木材比一般軟七夾更清楚，但整體仍比 Clipper 輕柔，形變、持球和上台率是主要優勢。
- 發力門檻低，適合建立摩擦、弧線與連續性；缺點是單板速度、遠台底勁和高強度對抗上限不如複合板或厚重七夾。
- 適合初中階練功、重視手感和控制的人；若已經依賴纖維板反彈，換到 SWAT 會覺得出球慢一檔。

#### 六組底板快速選擇

- 要近台速度、借力與反手銜接 → **銀河 PRO-01、三維 75 外置、W81 外置**
- 要持球、起下旋與連續弧圈 → **銀河 PRO-05、三維 75 內置、W81 內置、世奧得 VSEA**
- 要純木回饋、控制與動作養成 → **VICTAS SWAT**
- 預算低、第一次試內置 → **VSEA / PRO-05** 優先比較實際重量與柄型
- 想買 W81 或三維 75 → **先確認完整 SKU 與纖維縮寫**，再談內置 / 外置

- 正手球質、反手借力、整體輸出上限可能比較早碰到天花板

#### 適合誰
- 當年有手感記憶的人
- 備用、懷舊、低壓力練習用途

#### 一句話
**AKE 類更像一個時代的結構記憶，不太像現代兩面攻的高上限主戰解。**

---

## 十三、推薦閱讀路線：如果你現在用的是某一類，下一步可以看哪裡？

<div class="article-back-to-toc"><a href="#article-toc">↑ 回到目錄</a></div>

這一段不是在幫你直接選拍，
而是幫你快速決定：
**如果你已經知道自己喜歡哪一種手感，那下一步該往哪條線看。**

---

### 1. 如果你現在喜歡 Viscaria 類

你大概率喜歡的是：
- Koto 面材的清脆感
- 外置纖維的一速優勢
- 大甜區與現代均衡感

#### 下一步可以看
- 想要 **更柔一點** → Innerforce / 龍 5 類
- 想要 **更高輸出** → ZLC / SALC / SZLC 外置類
- 想要 **保留現代感但更便宜** → XVT 外置複合類

---

### 2. 如果你現在喜歡 Innerforce / 龍 5 類

你大概率喜歡的是：
- 持球感
- 弧圈味
- 內置那種「一開始不像纖維、發力後才撐出來」的節奏

#### 下一步可以看
- 想要 **更直接一點** → Viscaria 類
- 想要 **更純木感** → Acoustic / 高級五夾純木
- 想要 **更厚重純木支撐** → Clipper 類

---

### 3. 如果你喜歡 Clipper 類七夾純木

你大概率喜歡的是：
- 純木的厚實感
- 正手支撐
- 沒有纖維人工感，但又不會太軟

#### 下一步可以看
- 想要 **更高級純木細膩感** → Acoustic 類
- 想要 **更硬更脆的純木高級感** → Rosewood / Ebony 七夾系
- 想要 **加一點現代甜區** → 外置 ALC 類

---

### 4. 如果你喜歡單檜

你大概率喜歡的是：
- 木味
- 深吃球
- 單板爆衝的獨特節奏

#### 下一步可以看
- 想要 **保留木味但更穩** → Hinoki 面材多層板
- 想要 **更現代但還有吃球感** → Limba 內置類
- 想要 **保留手感但降低表層風險** → Walnut / Koto / Rosewood 類面材板

---

### 5. 如果你在意換膠時不要拔絲

你大概率應該優先看：
- Koto
- Walnut
- Rosewood
- Ebony

如果你喜歡 Limba / Hinoki 的手感，也不是不能選，
只是要把：
- 輕封板
- 拆膠手法
- 膠水控制

一起納入成本考量。

---

### 6. 如果你想要「高 CP 值升級感」

#### 比較常見的路線
- 老式純木 / 舊板 → XVT 外置複合類
- 傳統五夾純木 → Viscaria 類 / 外置 ALC 類
- 太軟太拖的板 → Koto outer 或更硬挺結構
