# 常見乒乓球底板型號完全對照表：結構、手感、定位與適合打法

這篇是 [`blade-materials`](/post/table-tennis/blade-materials/) 的延伸版。

如果說 `blade-materials` 講的是：
- 材料邏輯
- 結構位置
- 面材 / 力材 / 纖維 / 大芯的世界觀

那這篇處理的就是：

## **實際型號落地之後，它們彼此到底差在哪裡？**

也就是：
- Viscaria 和 Innerforce 到底不是只差 inner / outer（內置 / 外置）而已，整體世界觀差在哪？
- 龍 5、Clipper、Acoustic、單檜，各自最核心的手感主題是什麼？
- 如果我喜歡某一支，那下一步通常會往哪條線走？

## 二、各結構家族詳解

### 1. Viscaria 類（寇頭 / Koto + 外置芳碳 / Outer ALC）

#### 這類板的核心不是「有 ALC」而已
真正的主題是：
- 寇頭 / Koto 的拍面清晰感
- 外置纖維的小力量直出感
- 現代高級主戰板的整體均衡

#### 你會怎麼感覺到它？
- 小力量就有速度感
- 拍面很清楚
- 正反手都容易建立節奏
- 不太像純木那樣要慢慢含住球

#### 你如果喜歡它，通常代表你喜歡的是
- 清晰拍面
- 現代節奏
- 不要太拖
- 一上手就有外置纖維的效率感

#### 下一步會往哪裡走？
- 想更柔 → Innerforce / 龍 5 類
- 想更猛 → ZLC / SALC / SZLC 類
- 想找高 CP 值替代 → XVT 外置類

---

### 2. Innerforce ALC 類（林巴 / Limba + 內置芳碳 / Inner ALC）

#### 這類板的主題
不是「比較慢的 Viscaria」，
而是：

**高級純木感 + 纖維底勁。**

#### 你會怎麼感覺到它？
- 吃球時間比 Viscaria 長
- 一速不一定更快
- 但發力拉起來時有很舒服的後段支撐
- 比較適合把弧圈完整做出來

#### 喜歡這類的人通常喜歡
- 持球
- 旋轉層次
- 比較不躁進的節奏
- 內置那種「慢慢撐出來」的感覺

#### 下一步會往哪裡走？
- 想更快 → Viscaria 類
- 想更厚重弧圈 → 龍 5 類
- 想更純木 → Acoustic / 高級 5 夾純木

---

### 3. 龍 5 類

#### 這類板的主題
可以把它看成中國系弧圈內置板的代表。

它的重點不只是內置，
而是：
- 吃球更厚
- 正手大力拉時球質壓迫感更明顯
- 比較吃完整發力與節奏建立

#### 你會怎麼感覺到它？
- 一速可能不算特別爽快
- 但二速三速、特別是正手重板時會比較有「壓住球再撐出去」的感覺
- 比較有中國系正手大動作的味道

#### 喜歡這類的人通常喜歡
- 正手主動發力
- 弧圈厚重感
- 板身不是那種輕脆，而是比較有份量的節奏

#### 下一步會往哪裡走？
- 想更輕更直接 → Innerforce / Viscaria
- 想保留弧圈感但更細膩 → 高級純木五夾

---

### 4. Clipper 類（七夾純木 / 7-ply Wood）

#### 這類板的主題
是七夾純木的厚實骨架感。

#### 你會怎麼感覺到它？
- 板身很撐
- 正手不容易軟掉
- 純木但不會太拖
- 比五夾更直接、更厚實

#### 喜歡這類的人通常喜歡
- 純木的自然感
- 但又不想太柔太肉
- 想要中台也有支撐

#### 下一步會往哪裡走？
- 想更細膩 → Acoustic 類
- 想更硬朗高級 → Rosewood / Ebony 七夾
- 想更現代甜區 → Viscaria / 外置芳碳 / Outer ALC 類

---

### 5. Acoustic 類（五夾純木 / 5-ply Wood）

#### 這類板的主題
是高級五夾純木的細膩與持球。

#### 你會怎麼感覺到它？
- 木味好
- 小力量手感很細
- 吃球時間舒服
- 不靠刺激度取勝，而靠細膩與節奏

#### 喜歡這類的人通常喜歡
- 細節控制
- 手感層次
- 高級純木弧圈感

#### 下一步會往哪裡走？
- 想更厚實 → Clipper 類
- 想更現代 → Innerforce 類
- 想更有木味個性 → 單檜類

---

### 6. 單檜類（檜木 / Hinoki 單板）

#### 這類板的主題
不是均衡，
而是：

**木味、深吃球、單板爆發、手感成癮性。**

#### 你會怎麼感覺到它？
- 很有自己的節奏
- 球會吃得比較深
- 爆衝起來很爽
- 但整體容錯與泛用性不一定像現代複合板那麼舒服

#### 喜歡這類的人通常喜歡
- 木味
- 單板爆發
- 柔中帶彈、深吃球

#### 代表型號怎麼看？
先修正一點：**世奧德 橫濱悅不應直接歸成單檜。**

目前查到的公開資料比較像是：
- **橫濱悅（早期 / 基本款）**：常被描述成 **薄七層內加強型純木**
- **橫濱悅 精英版 / XI**：常被描述成 **5+2 外層加強型純木**
- **橫濱悅 2**：常見資料也指向 **內加強純木家族**，不是單檜單板

也就是說，它比較像是一整個：

## **橫濱悅純木家族**

核心主題是：
- 純木
- 加強結構
- 弧圈快攻
- 有日系風格手感，但不是單檜單板

#### 目前可整理出的細節（依公開網路資料）
- **厚度常見範圍：** 約 5.8mm（精英版 / 2 代常見）到 6.0–6.2mm 左右（部分早期 / 玩家實測描述）
- **重量常見範圍：** 橫板約 86–92g，直板常見更輕一些
- **常見打法定位：** 弧圈快攻型
- **常見手感描述：** 細膩、持球、純木底勁不錯、比一般老派純木更有加強結構的撐感
- **常被拿來比的方向：** 類似高級純木 / 納米 OC / 加強型純木弧圈板那條線，而不是 Clipper 厚七骨架派，也不是單檜爆衝派

#### 所以比較合理的放法是
- 不是 **單檜類**
- 也不完全等同於典型 **Clipper 類厚七夾**
- 更接近 **加強型純木弧圈快攻線 / 日系風格純木家族**

如果之後還要更細分，可以把它拆成：
- 橫濱悅（早期）
- 橫濱悅 精英版 / XI
- 橫濱悅 2

不然目前在總論裡，先以 **橫濱悅家族** 來看會比較準。\n\n> 備註：公開網路資料對不同版本的寫法並不完全一致，有些頁面寫薄七內加強，有些寫 5+2 外層加強；比較合理的解釋是它本來就有不同版本 / 世代，而不是單一固定結構。\n
#### 下一步會往哪裡走？
- 想更穩 → 檜木 / Hinoki 面材多層板
- 想更現代 → 內置芳碳 / Inner ALC、林巴 / Limba 內置類
- 想保留木味但更耐折騰 → 胡桃木 / Walnut、玫瑰木 / Rosewood 類

---

### 7. Rosewood / Ebony 七夾類（玫瑰木 / 黑檀木面材）

#### 這類板的主題
是硬派高級純木進攻感。

#### 你會怎麼感覺到它？
- 拍面緊
- 回饋清楚
- 一板球質漂亮
- 不會像 Limba 那樣柔和包球

#### 喜歡這類的人通常喜歡
- 硬朗純木
- 高支撐
- 不想靠纖維，但也不想太軟

#### 下一步會往哪裡走？
- 想更現代 → 外置 ALC / SALC 類
- 想更柔和 → Clipper / Acoustic 類

---

### 8. XVT 外置類

#### 這類板的主題
是「用比較可接受的成本先上現代外置路線」。

#### 你會怎麼感覺到它？
- 比老式純木和舊結構直接
- 拍面更清楚
- 升級感通常很明顯
- 一速和主動節奏容易拉上來

#### 喜歡這類的人通常喜歡
- 速度感
- 現代外置拍面
- 高 CP 值升級感

#### 下一步會往哪裡走？
- 想更成熟均衡 → Viscaria 類
- 想更高輸出 → SALC / ZLC 類

---

### 9. AKE / 老式結構類

#### 這類板的主題
比較像「熟悉感」而不是「現代高上限」。

#### 你會怎麼感覺到它？
- 順手
- 不陌生
- 但現代 40+ 球下，可能會覺得底勁、支撐、反手借力不夠

#### 喜歡這類的人通常喜歡
- 既有手感記憶
- 懷舊感
- 輕鬆打

#### 下一步會往哪裡走？
- 想現代升級 → XVT 外置類 / Viscaria 類
- 想保留木感 → Clipper / Acoustic 類

## 三、如果你只想看一句話版

### 你現在如果拿的是：
- **Viscaria 類** → 現代外置均衡主戰板
- **Innerforce / 龍 5 類** → 弧圈內置主戰板
- **Clipper 類** → 厚實純木進攻板
- **Acoustic 類** → 高級細膩純木板
- **單檜類** → 高風格木味派武器
- **Rosewood / Ebony 類** → 硬派高級純木進攻線
- **XVT 外置類** → 高 CP 值現代升級板
- **AKE 類** → 老時代手感記憶板

## 四、如果你現在的需求是：找便宜、可持續補貨、又接近 XVT 的快弧板

這其實是本篇很適合直接處理的一條支線。

如果你的出發點是：
- 現在喜歡 **XVT + 雙面 G-1**
- 想找 **大方向接近** 的替代線
- 接受不是 100% 原味，但希望是 **弱化版也可以**
- 重視 **大廠、補貨穩定、價格合理**

那目前可先這樣看：

### 第一梯隊：最像現代外置 / XVT 世界觀
- **銀河 PRO-1 / PRO-01**
- **銀河 PRO-05**
- **紅雙喜 博芳碳**

### 第二梯隊：現代純木快弧候選
- **YEO 7**
- **銀河 U2**
- **紅雙喜 勁極7**
- **三維 北歐七**

### 第三梯隊：更進攻、更撐、也更挑整體配置
- **YEO 7 Power**
- **三維 北歐七 Pro**
- **銀河 D-607**
- **紅雙喜 勁極7S / 勁極黑檀7S**

### 比較不像你現在這條主線的
- **Stiga S3000**

### 一句話版排序
**PRO-1 ≈ PRO-05 > 博芳碳 > YEO 7 > U2 ≈ 勁極7 ≈ 北歐七 > 北歐七 Pro ≈ YEO 7 Power ≈ D-607 > 勁極7S > 勁極黑檀7S > S3000**

如果你想看這批板的更完整版本（價格、厚度、重量、各自短評與對雙面 G-1 的相性），

## 五、怎麼用這篇？

最好的用法不是把每一支都背起來，
而是先問：

1. 你現在的板屬於哪個家族？
2. 你喜歡它的什麼？
3. 你不滿意它的什麼？
4. 下一步你是要：
   - 更快
   - 更吃球
   - 更穩
   - 更大甜區
   - 更有木味
   - 更抗拔絲

有了這四個答案，再回頭看對照表，
通常就會比單看品牌型號有效很多。
