這套 Build 來自鬼鬼（Onityan）的實測影片：[已玩壞遊戲《麥塊地下城 2》各種秒殺 BOSS！20 倍超級增傷](https://youtu.be/Y2B3GpuU2fU)。核心不是單純堆面板，而是利用 **劇毒尖牙持續施毒、全身毒素增傷，以及砂輪對毒傷異常高的實測倍率**，把原本約 60 的毒傷放大到 900～1300，再用攻速與爆擊把傷害密集灌進 BOSS。

> **版本提醒：** 影片發布於 2026-10-01；本文另以遊戲資料庫 build 1.1.1.0 的掉落資料交叉核對。砂輪與毒傷的高倍率可能是版本特性或數值異常，更新後若被修正，實際傷害可能下降。

## 核心原理：為什麼毒傷會暴增

### 1. 劇毒尖牙一次攻擊跳出多段傷害

劇毒尖牙是雙持短刃，每輪攻擊包含兩次命中；武器本身附帶毒傷，還會繼續觸發中毒跳傷。影片在 [00:16](https://youtu.be/Y2B3GpuU2fU?t=16) 展示基礎攻擊，單輪可同時看到武器白字、立即毒傷與後續中毒數字。

影片的重骰方向是：

- **毒素攻擊造成的傷害提高 20%**：直接放大整套 Build 的主傷害。
- **爆擊造成的傷害提高 20%**：與爆擊鞋、戰鼓一起放大爆發。

### 2. 四條毒素增傷堆到約 +80%

武器本身一條毒素增傷，加上三件神器各一條毒素增傷，合計約 **+80% 毒傷**。神器的第二效果可優先找 **靈魂容量 +30**，避免一次啟動三件神器後沒有靈魂續戰。

### 3. 砂輪對毒傷的實測倍率特別高

影片在 [01:03](https://youtu.be/Y2B3GpuU2fU?t=63) 比較不同屬性：

- 一般白字：約 2 倍。
- 冰、雷：約 3 倍以上。
- 火傷：約 1.5 倍上下。
- **毒傷：原本約 60，砂輪後跳到 900 多；先上毒再啟動時甚至超過 1300。**

這不是單純把「+20%」相加能得到的結果，而是影片版本中砂輪與毒傷計算的特殊交互作用。因此 **砂輪是不可替換的核心**；少了砂輪，這套仍是毒傷流，但不再是秒王流。

### 4. 攻速、爆擊與狀態延長補上最後一段

- 戰鬥真菌與兩件遊牧者防具提高出刀速度。
- 扭曲伏守者潛行鞋把近戰爆擊率提高 25%。
- 戰鼓讓爆擊再造成雙倍傷害。
- 蜂巢意志硬帽配合狀態延長護符，讓砂輪、戰鬥真菌與戰鼓的有效時間更長。
- 鐵拳與高血量增傷護符提供穩定乘區；打王前要先補滿血，維持生命高於 75%。

影片在 [02:24](https://youtu.be/Y2B3GpuU2fU?t=144) 同時啟動三件神器後，爆擊單段約 2500，所有傷害合計一刀可超過 8000。

## 實戰啟動順序

1. **先清小怪並補滿靈魂**：三件神器總消耗不低，打王前不要空魂進場。
2. **把生命補到 75% 以上**：啟動 Tendrils of the Sprout 的滿級 +40% 傷害。
3. **先開砂輪**：等磨刀動畫與增益圖示確實出現。
4. **再開戰鬥真菌與戰鼓**：取得攻速與爆擊增傷。
5. **跳砍進場後貼身連擊**：跳砍可快速觸發大範圍傷害，接著用雙刀攻速灌滿毒傷。
6. **遇到無敵階段就停手**：這套能跳過血量，但不能無視 BOSS 的鎖血或無敵機制。

## 不想賭爆擊：枯疫手環穩定版

如果還沒刷到爆擊鞋，或不想等待爆擊，可把 **戰鼓** 換成 **枯疫手環（Blight Bangle）**。它會再替攻擊注入一層劇毒，影片在 [02:49](https://youtu.be/Y2B3GpuU2fU?t=169) 實測每輪多兩個毒傷數字；砂輪啟動後，手環額外毒傷合計接近 1000。

- **爆擊版**：砂輪＋戰鬥真菌＋戰鼓，峰值最高，適合秒 BOSS。
- **穩定版**：砂輪＋戰鬥真菌＋枯疫手環，不依賴爆擊，清圖輸出更穩。

若已取得 **Fighter's Flute**，也可測試用它取代戰鬥真菌。當前社群資料把「Fighter's Flute＋戰鼓」視為強力爆擊組合；不過這不是原影片使用的版本，因此本文仍以影片配置為主。

## 全裝備取得方式

### 劇毒尖牙

- **掉落區域**：咆哮森林（Howling Woods）、深暗之域（The Deep Dark）、雨水原野（Rainy Plains）。
- **取得規則**：它是 **雙匕首（Double Daggers）的獨特變體**；任何會掉雙匕首的戰利品，都有機會升格為劇毒尖牙。
- **其他來源**：部分任務獎勵也會給予。
- **建議刷法**：先刷咆哮森林，因為同區也能重跑護符「鐵拳」的任務。

### 砂輪

- **掉落區域**：深暗之域、安眠丘陵（Lullaby Hills）。
- **影片提示**：[04:12](https://youtu.be/Y2B3GpuU2fU?t=252) 直接在安眠丘陵的區域掉落表中展示。
- **消耗／冷卻**：30 靈魂、4 秒冷卻。
- **刷到後要做的事**：到鐵匠重骰毒素傷害 +20%；第二條優先靈魂容量或冷卻相關效果。

### 戰鬥真菌

- **掉落區域**：冰封高地（Frozen Highlands）、轟鳴蟲殼之地（Humbler Huskland）。
- **消耗／冷卻**：20 靈魂、5 秒冷卻。
- **用途**：只負責提高攻速，本身不直接增傷；尚未完成爆擊循環時也很好用。

### 戰鼓

- **掉落區域**：深暗之域、安眠丘陵。
- **其他來源**：可由任務獎勵取得。
- **消耗／冷卻**：45 靈魂、5 秒冷卻。
- **用途**：讓爆擊造成雙倍傷害；沒有穩定爆擊來源時，優先度低於枯疫手環。

### 枯疫手環

- **掉落區域**：勇士避風港（Brave Haven）、冰封高地、蜂巢原野（Honeycomb Fields）。
- **消耗／冷卻**：35 靈魂、6 秒冷卻。
- **用途**：額外注入毒傷，取代戰鼓成為不依賴爆擊的穩定版本。

### 蜂巢意志硬帽

- **掉落區域**：勇士避風港、蜂巢原野。
- **取得規則**：它是 **養蜂人面紗（Beekeeper Veil）的獨特變體**。
- **其他來源**：任務獎勵也可取得；影片指出蜂巢原野任務會送，之後同區仍可重刷。
- **核心效果**：自己與隊友的正面狀態延長 70%，大幅拉長三件神器的爆發窗口。

### 遊牧者胸甲與遊牧者護腿

- **掉落區域**：冰封高地、歌者草甸（Singer's Meadow）。
- **其他來源**：任務獎勵。
- **重骰目標**：胸甲近戰攻速約 +20%；護腿近戰攻速至少 +15%，能骰到 +20% 更好；剩餘效果補減傷。
- **注意**：影片選這兩件主要是為了隨機效果，不是套裝加成；二代防具各自生效，沒有必須穿滿四件的套裝獎勵。

### 扭曲伏守者潛行鞋

- **掉落區域**：深暗之域、安眠丘陵。
- **取得規則**：它是 **伏守挖掘者靴（Sculk Digger Boots）的獨特變體**，不必只等特定 BOSS；該區任何能掉基底靴的獎勵都有機會升格。
- **核心效果**：近戰爆擊率 +25%。
- **重骰目標**：第二效果補受傷降低；若暫時刷不到，可先用任何帶爆擊率或近戰增傷的鞋過渡。

## 三枚護符怎麼拿

護符要裝備並累積經驗才會升級；本文列的是影片滿級數值。

### 鐵拳（Fist of Iron）

- **效果**：滿級近戰傷害 +35%。
- **任務**：咆哮森林主線 **The Missing Note Blocks**。
- **取得方式**：不是首通固定獎勵，要重跑任務，從重複完成獎勵中取得。

### Tendrils of the Sprout

- **效果**：滿級且生命高於 75% 時，傷害 +40%。
- **任務**：深暗之域主線 **Returning the Note Blocks**。
- **取得方式**：第一次完成固定獎勵。

### Sculk Badge

- **效果**：延長施加在自己身上的正面狀態；影片滿級顯示 +25%。
- **任務**：冰封高地支線 **Illager Intelligence**。
- **取得方式**：重跑任務，從重複完成獎勵中取得。

## 最省時間的成形順序

1. **咆哮森林**：先解 The Missing Note Blocks，刷劇毒尖牙與鐵拳。
2. **深暗之域／安眠丘陵**：集中刷砂輪、戰鼓、扭曲伏守者潛行鞋，並完成 Returning the Note Blocks 拿高血量增傷護符。
3. **冰封高地**：刷戰鬥真菌、遊牧者胸甲／護腿，並重跑 Illager Intelligence 拿狀態延長護符。
4. **蜂巢原野／勇士避風港**：刷蜂巢意志硬帽與枯疫手環；想改爆擊笛版本也可一起刷 Fighter's Flute。
5. **物品強度接近封頂後再重骰**：武器與三神器先追毒素傷害，防具再追攻速、減傷與冷卻。

## 畢業檢查表

- 劇毒尖牙有毒素增傷，爆擊版再補爆擊傷害。
- 砂輪、戰鬥真菌、戰鼓各有毒素傷害 +20%。
- 至少一件神器帶靈魂容量，能連續啟動完整爆發循環。
- 鐵拳、Tendrils of the Sprout、Sculk Badge 都已練滿。
- 胸甲與護腿合計提供約 35～40% 近戰攻速。
- 爆擊版裝備扭曲伏守者潛行鞋；未完成前先用枯疫手環穩定輸出。
- 打王前保持滿血、滿魂，並確認砂輪圖示出現再進場。
