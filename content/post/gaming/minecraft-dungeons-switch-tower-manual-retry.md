高塔（Tower）挑戰性高，失敗就會重置進度。透過關閉 Nintendo Switch 的雲端**自動**備份，改用**手動**上傳/下載存檔，就能無限次重試高塔，直到滿意為止。

## 步驟一：關閉《Minecraft Dungeons》雲端自動上傳

1. 遊玩中按 **HOME** 鍵回主選單
2. 游標移到《Minecraft Dungeons》圖示上（不要打開遊戲）
3. 按 `+` 或 `-` 進入「選項」
4. 選左側「儲存資料雲端備份」
5. 將「自動備份」改為「關閉」

> 此設定只影響本遊戲，其他遊戲的自動備份不受影響。

## 步驟二：手動上傳/下載存檔來重試高塔

### 進塔前先手動上傳（建立起點存檔）

1. 在安全區域（如營地）
2. HOME → 選圖示 → `+`/`-` → 「儲存資料雲端備份」
3. 選「備份儲存資料」，上傳目前進度作為「高塔起點」
4. 繼續遊戲，進入高塔

### 失敗後手動下載（重置回起點）

1. 高塔失敗或想重來
2. HOME → 選圖示 → `+`/`-` → 「儲存資料雲端備份」
3. 選「下載儲存資料」→ 選擇覆蓋本機存檔
4. 繼續遊戲，即回到上傳當下的狀態，可再次挑戰高塔

## 總結

靠這個手動上傳/下載存檔的技巧，就能在《Minecraft Dungeons》裡無限重試高塔，直到打出滿意的戰利品或掌握最佳策略為止。
