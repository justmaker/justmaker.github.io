## 遊戲概覽

Minecraft Dungeons 是一款基於 Minecraft 世界觀的合作動作 RPG。玩家最多 4 人組隊，穿越各種地牢擊敗 Arch-Illager。沒有職業系統，角色能力完全由**裝備 + 附魔**決定。

---

## 基本操作

| 動作 | 按鍵（Switch / PC） |
|------|---------------------|
| 攻擊 | A / 左鍵 |
| 遠程射擊 | ZR / 右鍵 |
| 翻滾閃避 | B / 空白鍵 |
| 使用法器 | X, Y / 1, 2, 3 |
| 查看地圖 | - / M |
| 治療藥水 | L / Q |

> 翻滾有 i-frame（無敵幀），是躲 Boss 大招的核心手段。

---

## 難度系統

遊戲有三個大階段，每個階段內有多個難度等級：

- **預設（Default）** → 第一輪，戰力 1–25
- **冒險（Adventure）** → 通關主線後解鎖，戰力 26–50
- **天啟（Apocalypse）** → 通關冒險後解鎖，戰力 51–115
- **天啟+（Apocalypse+）** → 天啟後追加 +1 到 +25 難度

每個關卡可以調整推薦戰力，越高掉落裝備等級越好。

## 主線關卡流程

### 1. 魷魚海岸（Squid Coast）— 教學關
- 學會移動、攻擊、射箭、翻滾
- 撿取法器裝備
- 完成後進入**營地**

### 2. 苦力怕森林（Creeper Woods）
- **目標：** 拯救村民
- 注意苦力怕會自爆，遠距離擊殺或引爆後閃避
- 路上有 TNT 可撿來炸蜘蛛群
- 🔒 **隱藏任務：** 陰森墓穴（Creepy Crypt）— 在地圖中找到隱藏入口

### 3. 南瓜牧場（Pumpkin Pastures）
- **Boss：** 喚魔者（Evoker）— 會召喚尖牙從地面攻擊
- 打法：持續移動，優先殺召喚物
- 🔒 **隱藏任務：** 拱門港灣（Arch Haven）

### 4. 潮濕沼澤（Soggy Swamp）
- **目標：** 摧毀 5 個釀造廠，找到煉藥鍋
- **Boss：** 末影人 + 腐化鍋釜巨怪（Corrupted Cauldron）
- 巨怪會在周圍撒毒，保持距離用遠程輸出
- 沒血可以往回跑等回復
- 🔒 **隱藏任務：** 潮濕洞穴（Soggy Cave）

### 5. 仙人掌峽谷（Cacti Canyon）
- 地圖較長，注意環境陷阱
- 多利用翻滾避開遠程攻擊

### 6. 紅石礦場（Redstone Mines）
- **Boss：** 紅石魔像（Redstone Golem）— 體型巨大，會衝撞和範圍攻擊
- 打法：引誘攻擊 → 翻滾閃避 → 趁硬直輸出

### 7. 沙漠神殿（Desert Temple）
- **Boss：** 末影人（再次出現）
- 🔒 **隱藏任務：** 下層神殿（Lower Temple）

### 8. 熾熱鍛爐（Fiery Forge）
- 地圖有岩漿環境傷害，注意腳下
- 敵人密度高，帶 AoE 附魔會很舒服

### 9. 高塔大廳（Highblock Halls）
- 精英敵人增多
- 🔒 **隱藏任務：** 地下大廳（Underhalls）

### 10. 黑曜石尖塔（Obsidian Pinnacle）— 最終關
- **最終 Boss：** Arch-Illager → 末影之心（Heart of Ender）
- Arch-Illager 階段：躲避召喚物和投射物
- 末影之心階段：巨大 Boss，有鐳射攻擊和範圍衝擊波
- 打法：貼近打腳 → 看到蓄力就翻滾拉開 → 重複

### 🐄 隱藏彩蛋關：祕密牛關（Secret Cow Level）
- 收集所有地圖中的特殊符文開啟
- 全是牛和蘑菇牛，超大量裝備掉落，刷裝聖地

## 裝備系統

裝備分三類：

### 近戰武器

## 附魔推薦

### 近戰附魔 Tier List
- **S 級：** 旋風（Swirling）、鎖鏈（Chains）、雷鳴（Thundering）、暴擊（Critical Hit）
- **A 級：** 回復（Leeching / Radiance）、刺探（Committed）、發光（Sharpness）
- **B 級：** 火焰（Fire Aspect）、毒雲（Poison Cloud）、狂暴（Frenzy）

### 遠程附魔 Tier List
- **S 級：** 多重箭（Multishot）、連鎖反應（Chain Reaction）、穿透箭（Piercing）
- **A 級：** 重力射擊（Gravity）、蓄力射擊（Power）、節約彈藥（Infinity）
- **B 級：** 快速裝填（Rapid Fire）、擊退射擊（Punch）

### 盔甲附魔 Tier List
- **S 級：** 藥水護盾（Potion Barrier）、閃避（Deflect）、荊棘（Thorns）
- **A 級：** 生命提升（Health Synergy）、減傷（Protection）、靈魂加速（Soul Speed）
- **B 級：** 速度提升（Speed Synergy）、食物儲備（Food Reserves）

## META 配裝推薦

### 🪓 斧頭鬥士流（最強通用）
- **近戰：** 戰斧 / 雙斧 — 附魔：旋風 + 暴擊 + 回復
- **遠程：** 豎琴弓 — 附魔：多重箭 + 連鎖反應 + 穿透箭
- **盔甲：** 任意重甲 — 附魔：藥水護盾 + 荊棘 + 閃避
- **法器：** 毒帽菇 × 2 + 驚嚇鑼
- **打法：** 開雙蘑菇 BUFF 不間斷，看到 Boss 先敲鑼再剁

### 👻 靈魂流
- **近戰：** 靈魂鐮刀 — 附魔：靈魂吸取 + 旋風 + 暴擊
- **遠程：** 靈魂弓 — 附魔：靈魂採集 + 穿透箭 + 蓄力
- **盔甲：** 靈魂長袍 — 附魔：靈魂加速 + 藥水護盾
- **法器：** 靈魂治療圖騰 + 腐蝕噴霧 + 採集手套
- **打法：** 靠擊殺快速充能法器，持續釋放技能

## 生物優先擊殺順序

1. **苦力怕** — 會自爆，最優先
2. **喚魔者** — 召喚尖牙，不處理會被圍
3. **女巫** — 投擲藥水，持續騷擾
4. **骷髏弓箭手** — 遠程持續輸出，先清
5. **附魔者** — 會給其他怪加 BUFF
6. **紅石魔像** — 血厚傷高，但動作慢可以最後打

---

## 高塔（Tower）

- 通關主線後解鎖
- 每次進入隨機 30 層，裝備固定（不能帶自己的）
- 每層給隨機裝備選擇，逐步搭配 build
- 打敗第 30 層 Boss 可獲得**最高等級裝備（263 級）**
- 是取得頂級裝備最有效率的方式

---

## 刷關推薦

### 奇厄藏身處（Cacti Canyon / Arch Haven）
- 地圖小、怪多、寶箱密集
- 有 2 個隱藏大寶箱位置（地圖邊緣和隱藏房間）
- 反覆刷取可快速提升戰力和裝備品質

### 祕密牛關
- 解鎖後最佳刷裝地點
- 大量弱怪 + 高掉率

## 新手 Tips

1. **翻滾是免費的** — 多用翻滾，少硬吃傷害
2. **別急著用附魔點** — 可以回收，但早期試錯浪費時間
3. **戰力 ≠ 實力** — 好的附魔搭配比純數值更重要
4. **藥水有冷卻** — 不要浪費在小傷上
5. **多人比單人簡單很多** — 可以互相復活
6. **每個關卡都值得回去探索** — 隱藏區域有好東西
7. **營地會隨進度解鎖新 NPC** — 記得回去看看
